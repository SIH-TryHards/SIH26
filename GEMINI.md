# Rule: Professional Tone & Minimalist UI

**UI Design Directive:**
- Keep all UI elements minimal.
- Use small symbols and small bounding boxes (paddings/margins).
- The overall look should be clean, tight, and pleasing to the eyes.
- Never use emojis in UI text, code, artifacts, or chat responses unless explicitly requested as specific UI iconography (e.g., standard weather symbols). Maintain a strict, professional, and formal tone at all times.

**Localhost Links:**
Always provide a clickable localhost link (e.g., [http://localhost:8080](http://localhost:8080)) when discussing the live application so the user can easily navigate to it.
