TECH STACK AND TECHNOLOGIES USED

## Frontend / User Interface
- React.js (Web Application)
- Multilingual Support (Text & Voice)
- Features: Farmer Dashboard, Advisories & Alerts, Loan Calculator

## Backend / Application Layer
- Node.js & Express.js (RESTful API)
- Authentication: JWT
- Notifications Service: Twilio / MSG91 (Email/SMS/Voice)

## Database & Storage
- PostgreSQL (Relational Database)
- File Storage for Images & Docs

## Processing & AI Engine
- Python
- Machine Learning Models: Risk Analysis, Recommendations (TensorFlow / Scikit-learn)
- Data Preprocessing & Validation
- Rule Engine (Business Rules)
- AI Advisory Engine

## Data Ingestion & Sources
- ETL Pipelines
- Weather APIs, Soil Data, Crop & Mandi Prices, Government Schemes & Guidelines, Farmer Input

## Cloud & Infrastructure
- AWS (Amazon Web Services)
- Firebase

## System Flow
1. Collect Data
2. Store Data
3. Process & Analyze (AI Engine)
4. Generate Advisory & Alerts
5. Deliver to Farmer (Web / SMS / Voice)
6. Feedback & Improvement
